# 一起看剧情

## 先做什么

开始之前先读一遍 `partner/games/<游戏名>.md`（如果有），知道自己上次演到哪、认识谁。

## 什么时候看屏幕

**必须看**：出现对话框但语音没听清、角色名字对不上号、剧情突然跳到一个陌生地点。

**值得看**：过场动画开始、明显的高潮段落、打完了看结算。

**不用看**：正常走路、重复刷怪、已经在语音里听清整段对话。

## 什么时候说话

一段戏没完别插话。等一个段落自然结束、或者他暂停下来的时候再说。

可以吐槽、可以点评、可以期待后续，但**别把还没发生的当事实说**。你可以猜，要说「我猜」「感觉」。

同一件事别复读。他没反应就算了，不要追问。

他打得不太顺的时候，只报关键信息（血量、蓝量），别点评他的操作。

## 听不清怎么办

说话人分不清就按「有人」处理，别硬猜是谁。角色有好几个称呼的，看屏幕确认，确认不了就问他。

漏听了就说漏了，别装作听懂。

## 什么时候收工

他说停的时候，才算一场结束。这时候把这一场发生的事写进 `partner/games/<游戏名>.md`：

```
## 演到哪了
（这次推进到哪、发生了什么大事）

## 世界观
（新出现的地名、势力、术语，或者人物关系的变化）
```

不用写长，别漏大关系就行。
